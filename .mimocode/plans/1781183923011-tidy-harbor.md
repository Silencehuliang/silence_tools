# 简化认证系统 - 用户名/密码注册登录

## 概述
将现有的 GitHub/Gitee OAuth 登录替换为简单的用户名/密码系统。支持注册、登录、忘记密码（管理员审批）。

---

## 一、数据库 Schema 变更

### 新 users 表
```sql
-- 重建 users 表（去掉 provider/provider_id，增加 password_hash）
DROP TABLE IF EXISTS users;
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,         -- PBKDF2 哈希
  password_salt TEXT NOT NULL,         -- 随机盐
  role TEXT DEFAULT 'user' CHECK(role IN ('user', 'admin')),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 密码重置申请表
CREATE TABLE IF NOT EXISTS password_resets (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL,
  status TEXT DEFAULT 'pending' CHECK(status IN ('pending', 'approved', 'rejected')),
  requested_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  reviewed_at DATETIME,
  reviewed_by INTEGER,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

-- 初始化管理员账号（密码 silence.h）
-- 需要通过 API 或脚本初始化
```

## 二、密码安全方案

使用 Web Crypto API 的 PBKDF2：
- 迭代次数: 100,000
- 盐: 16字节随机数
- 哈希: SHA-256
- 输出: base64 编码

```
密码 → PBKDF2(password, salt, 100000, SHA-256) → hash
存储: { salt, hash }
验证: PBKDF2(input_password, stored_salt, 100000, SHA-256) == stored_hash
```

## 三、API 接口变更

### 删除的接口
- `/api/auth/github`
- `/api/auth/github/callback`
- `/api/auth/gitee`
- `/api/auth/gitee/callback`

### 新增接口

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | `/api/auth/register` | 注册 | 否 |
| POST | `/api/auth/login` | 登录 | 否 |
| POST | `/api/auth/logout` | 登出 | 是 |
| GET | `/api/auth/me` | 当前用户 | 是 |
| POST | `/api/auth/reset-request` | 申请重置密码 | 否 |
| GET | `/api/admin/reset-requests` | 查看重置申请 | 管理员 |
| POST | `/api/admin/reset-requests/:id/approve` | 批准重置 | 管理员 |
| POST | `/api/admin/reset-requests/:id/reject` | 拒绝重置 | 管理员 |

### 请求/响应格式

**注册 POST /api/auth/register**
```json
// 请求
{ "username": "user1", "password": "xxx" }
// 响应
{ "success": true, "user": { "id": 1, "username": "user1" } }
```

**登录 POST /api/auth/login**
```json
// 请求
{ "username": "user1", "password": "xxx" }
// 响应 200
{ "success": true, "user": { "id": 1, "username": "user1" } }
// 响应 401
{ "error": "用户名或密码错误" }
```

## 六、管理员功能

管理员 (silence) 登录后，首页显示管理入口：
- 查看待审批的密码重置申请列表
- 批准/拒绝操作
- 批准后用户可使用新密码登录（密码重置为默认值或随机密码）

## 七、安全措施

1. **密码传输**: 前端发送明文密码（HTTPS 加密传输），后端 PBKDF2 哈希后存储
2. **Session**: HttpOnly + Secure + SameSite=Lax cookie
3. **防暴力破解**: 登录失败返回通用错误信息（不透露用户名是否存在）
4. **管理员接口**: 需要 session 中 role=admin 才能访问
5. **CORS**: 只允许 Pages 域名访问
